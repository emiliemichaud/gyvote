Confidentialité

Données personnelles

Quelles données sont collectées ?

Cette application ne demande ni nom, ni adresse e-mail, ni aucune autre donnée d'identification directe. Les seules données enregistrées sont :

  • Un identifiant anonyme aléatoire (une longue suite de caractères sans signification), généré par votre navigateur la première fois que vous ouvrez un lien de vote. Il sert uniquement à garantir qu'une même personne ne vote qu'une seule fois par session.
  • Le choix de vote (Pour / Contre / Abstention) associé à cet identifiant et à la session concernée.

Où ces données sont-elles stockées ?

  • Dans votre navigateur (stockage local, "localStorage") : l'identifiant anonyme mentionné ci-dessus, propre à cet appareil et ce navigateur.
  • Dans une base de données Supabase (hébergement cloud du projet — Europe ) : l'identifiant anonyme et le choix de vote, ainsi que le code et le statut de la session.
  • Les fichiers de l'application eux-mêmes sont hébergés sur GitHub Pages, accessible via le nom de domaine vote.gymnase-etoy.ch.

Combien de temps ces données sont-elles conservées ?

Chaque session (et les votes qui lui sont associés) est supprimée automatiquement au plus tard 15 heures après sa création. L'organisateur peut aussi la clôturer manuellement à tout moment, ce qui supprime immédiatement toutes les données de cette session.

Le vote est-il anonyme ?

Oui : rien dans l'application ne relie l'identifiant technique utilisé à votre identité réelle. Cet identifiant sert uniquement à empêcher les votes multiples au sein d'une même session.
